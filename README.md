# ドライブスタフ（段階1 試作）

鉄道の運転士用「運行スタフ」の考え方で、車・バイクの移動を支援するスマホ用 Web アプリ（PWA）。
要件定義・計画書はこのリポジトリには含めない。

## 段階1でできること
- 行程（地点名・座標・予定の着発時刻）の入力と端末内保存
- 地点ごとの予定・見込み・差（±5分以内は定時）の表示
- GPS による到着・出発の自動判定（半径100m以内で1分停車＝到着／範囲外へ走り出す＝出発／止まらず通過＝通過扱い）
- 画面下部の常設ボタン（到着・出発）。走行中は押せない。予定地点の200m以内では「到着」を大きく表示
- 次の地点までのナビを Google マップアプリへ受け渡す
- 縦横の切替（自動／横固定／縦固定）、画面の消灯防止、オフライン動作
- 診断画面（実機確認 T1〜T7 の記録）

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `app.js` | 判定・計算・表示の処理 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフライン用のキャッシュ（ファイルを更新したら `VERSION` を上げる） |
| `robots.txt` | 検索エンジンに載せない設定 |

## PC での確認
URL の末尾に `?sim=1` を付けると、GPS の代わりに行程どおり走るシミュレーションで動く（速さ ×1／×10／×60、渋滞 +10分）。

## データについて
旅程・走行記録・診断記録は端末のブラウザ内にだけ保存される。このリポジトリやサーバーには送られない。
